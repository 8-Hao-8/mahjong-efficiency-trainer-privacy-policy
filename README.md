# Privacy Policy (ツモって何切る)

このリポジトリは、アプリ「ツモって何切る」のプライバシーポリシー公開用です。

公開URL（GitHub Pages）を App Store Connect / Google Play の Privacy Policy URL に設定します。

2026-08-12時点で、広告、IAP、中級 backend 通信、ご意見箱、任意メールアドレス、診断情報、中級局面データ、Google Apps Script / Gmail 経由の受信を反映済みです。

広告非表示の権利状態と購入回収の進行状態は端末内に保存し、Storeの購入トークンや署名済み取引データをアプリ側で永続保存しないこと、購入済みと確認できる次回起動ではATT許可要求と広告SDK初期化を行わないことを明記しています。
